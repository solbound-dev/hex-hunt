# Hextraction: Battleship for degens :rocket:

[Play it here!](https://hextraction.xyz/login)

## Turn based PvP stealth game

Multiplayer strategy game based on hidden movements on a hexagonal grid. Space-themed, shrinking world, shoot and collect cards to win, don’t die in the process. Mix of battleship, checkers and connect four.
